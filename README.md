# 🚗 Rideshare App (HTCHHKR)

App de viajes compartidos para iOS construida con Swift y UIKit. Permite al usuario elegir su ubicación, buscar un destino y solicitar un viaje sobre un mapa.

## ✨ Características

- Mapa con Apple Maps (MapKit)
- Tarjeta de origen y destino con diseño de sombra redondeada
- Botón "Request Ride" con animación de carga
- Botón para centrar el mapa en tu ubicación
- Interfaz con Auto Layout adaptable a distintos iPhones

## 🛠 Tecnologías

- Swift
- UIKit + Storyboards
- MapKit
- Auto Layout

## 📱 Requisitos

- Xcode 15 o superior
- iOS 15+

## ▶️ Cómo ejecutarlo

```bash
git clone https://github.com/alex-hort/Rideshare-App.git
cd Rideshare-App
open Rideshare-App.xcodeproj
```

Selecciona un simulador y presiona `⌘ + R`.
